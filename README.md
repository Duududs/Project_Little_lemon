O **Little Lemon é o projeto final (capstone) do Certificado de Desenvolvedor Front-End da Meta**, oferecido na plataforma Coursera.

Este projeto tem como foco a construção de uma aplicação web moderna, responsiva e acessível, utilizando React e práticas modernas de desenvolvimento front-end.

A aplicação simula a experiência de um restaurante, onde os usuários podem explorar informações e interagir com a interface de forma fluida e intuitiva.

---

###  ﾟ Como rodar o projeto localmente 

```bash
git clone https://github.com/your-username/little-lemon-app.git
cd little-lemon-app
npm install
npm start
```
